Проект

О нас

Fan-made справочник для игроков, которым нужен быстрый, чистый и расширяемый источник знаний.

Создатель

Собрано для тренировок

Сайт сделан как локальный кодекс: открыл через Live Server и пошёл сверять героя, карту или термин.

Цель

Меньше хаоса, больше понимания

Главная идея — хранить полезные данные рядом с красивым интерфейсом, чтобы любой раздел можно было расширить без backend и сборщиков.
