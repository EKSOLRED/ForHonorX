# ForHonorX

Локальный справочник по For Honor: герои, способности, перки, добивания, карты, механики, терминология и тир-листы.

## Запуск

Открой проект через Live Server или любой локальный статический сервер. Прямое открытие HTML-файлов через `file://` может мешать части браузерной логики.

## Проверка данных

```bash
node tools/validate-data.js
```

Валидатор проверяет героев, каталог, карты, способности, перки, добивания, глоссарий, ссылки на изображения и базовые дубли `id`.

## Правила поддержки

- CSS подключается слоями через `css/main.css`; не превращай его обратно в один монолит.
- Общие переменные хранятся в `css/core/00-theme.css`.
- Локальные начертания Bebas Neue хранятся в `assets/fonts/` и подключаются через `@font-face`.
- Данные героя лежат в `js/data/heroes/<hero-id>/` по отдельным блокам: база, приёмы, добивания, наказания, способности, перки, гайд, озвучка.
- Одинаковые `index.js` в папках героев удалены: подключение делает общий `js/data/hero-loader.js`.
- Не добавляй `!important` без крайней необходимости: сначала исправляй порядок подключения и специфичность селектора.
